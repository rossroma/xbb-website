## 2. 内容管理（文章发布）

### 2.1 功能入口

后台左侧菜单 → **内容管理**

### 2.2 界面说明

页面分为左右两栏：

- **左栏**：栏目分类树，按层级展示所有栏目，点击后只看该栏目下的文章
- **右栏**：文章列表，支持搜索标题、按状态筛选、推荐筛选

### 2.3 文章发布到前台的过程

```
后台新增文章 → 选择所属栏目 → 设为"显示" 
    → 前台对应栏目页面自动展示该文章
```

关键规则：**一篇文章属于一个栏目，选择哪个栏目，它就会出现在前台哪个栏目页上。**

### 2.4 文章编辑字段说明

后台编辑页面分为三个标签页：

#### 基本信息

| 字段 | 必填 | 说明 |
|------|------|------|
| **标题** | 是 | 1-60 个字符，前台文章标题 |
| **所属分类** | 是 | 决定这篇文章出现在前台的哪个栏目下 |
| **权重** | 否 | 数字越小，在列表中的排序越靠前 |
| **状态** | 是 | 「显示」= 前台可见，「隐藏」= 前台不可见（草稿） |
| **详细内容** | 否 | 文章正文，使用富文本编辑器编辑，支持图片、表格等 |

#### SEO 设置

| 字段 | 说明 |
|------|------|
| **SEO 标题** | 浏览器标签栏显示的文字，不填默认取文章标题 |
| **SEO 关键词** | 页面搜索引擎关键词，多个用逗号隔开 |
| **SEO 描述** | 搜索引擎结果中显示的摘要，50-200 字为宜 |

#### 高级信息

| 字段 | 说明 |
|------|------|
| **副标题** | 部分列表组件会展示 |
| **信息描述** | 列表页中的文章摘要，50-150 字 |
| **作者** | 文章作者，选填 |
| **来源** | 转载出处，选填 |
| **访问量** | 初始浏览量，可手动设置 |
| **缩略图** | 列表页展示的卡片图片，建议 380×239 像素 |
| **推荐类型** | 勾选后，文章在列表页会显示「推荐」标签 |
| **发布时间** | 可以设置未来时间，实现定时发布 |

### 2.5 文章生命周期

```
新增文章 → 设为"隐藏"（草稿状态）→ 编辑完成 → 改为"显示" → 前台可见
                                                              ↓
                回收站 ← 删除文章（前台不再展示，后台可恢复）
                                                              ↓
                彻底删除（不可恢复）
```

### 2.6 操作步骤

#### 新增文章
1. 进入「内容管理」，在左侧栏目树中点击目标栏目（快速定位）
2. 点击「新增」按钮，选择所属分类
3. 填写标题，编辑正文
4. 切换到「高级信息」标签，设置缩略图、推荐等
5. 切换到「SEO 设置」标签，填写 SEO 信息
6. 点击「提交」完成

#### 编辑/删除
- 在文章列表中点击「修改」可编辑
- 点击「删除」文章移入回收站
- 回收站中可「还原」或「彻底删除」

### 2.7 不同内容类型的区别

虽然新闻、案例、用户心声、知识问答都通过「内容管理」发布，但它们在**内容格式要求**和**前台展示方式**上有所不同。发文章时请根据下表选择正确的分类并填写对应字段。

#### 新闻动态

| 项目 | 说明 |
|------|------|
| **选择分类** | 公司动态 / 行业动态 / 媒体报道 |
| **前台页面** | `/gongsidongtai` 列表页 → 点击进入详情页 |
| **必填字段** | 标题、正文、所属分类 |
| **重要字段** | 缩略图（列表卡片展示）、作者、来源 |
| **内容要求** | 标准新闻文章，图文并茂，客观报道 |
| **详情页展示** | 标题、分类标签、发布时间、作者、来源、阅读量、正文 |

#### 行业案例

| 项目 | 说明 |
|------|------|
| **选择分类** | 行业案例下的子分类（如互联网行业、制造业等） |
| **前台页面** | `/hangyeanli` 列表页 → 点击进入详情页 |
| **必填字段** | 标题、正文、所属分类、**配图** |
| **重要字段** | **配图**（必填，作为案例卡片大图展示）、行业标签 |
| **内容要求** | 以客户成功故事为主线，突出使用效果和数据 |
| **详情页展示** | 大图 + 标题 + 描述 + 正文 + 标签 + 相关案例推荐 |

#### 用户心声

| 项目 | 说明 |
|------|------|
| **选择分类** | 用户心声下的子分类（按行业） |
| **前台页面** | `/yonghuxinsheng` 卡片网格，**无详情页** |
| **必填字段** | 标题（客户名称）、**描述**（评价内容）、**配图**（客户 Logo） |
| **重要字段** | 描述（展示在卡片上的评价文字）、配图（客户 Logo 图） |
| **内容要求** | 以客户口吻写一段正面评价，简洁有力，不需要长篇正文 |
| **前台展示** | 卡片网格形式，展示 Logo + 客户名称 + 评价文字，**不支持点击进入详情** |

#### 知识问答

| 项目 | 说明 |
|------|------|
| **选择分类** | 知识问答 |
| **前台页面** | `/zhishiwenda` 列表页 → 点击进入详情页 |
| **必填字段** | 标题（问题）、正文（答案） |
| **重要字段** | 信息描述（作为摘要展示在标题下方）、正文中的小标题（自动生成目录导航） |
| **内容要求** | 标题 = 问题（如"CRM 系统如何帮助销售团队提升效率？"），正文 = 回答，建议用多级小标题组织内容 |
| **详情页展示** | 标题 + 摘要 + 正文 + 右侧目录导航 + 底部相关 FAQ |

> **注意**：以上四种类型的文章都在同一个后台「内容管理」中操作，区别在于**选择不同的分类**，文章就会出现在前面对应的页面上。

### 2.8 内容发布规范

| 项目 | 建议 |
|------|------|
| 标题长度 | 10-30 个字 |
| 摘要描述 | 50-150 字，包含关键词 |
| 缩略图 | 380×239 像素 |
| 正文图片 | 先上传到系统再使用，不要用外链 |
| 关键词 | 在标题和正文中自然出现 2-3 次 |

## 3. 广告管理（Banner 轮播管理）

### 3.1 功能入口

后台左侧菜单 → **广告管理**

### 3.2 两级管理结构

广告管理分为两步：

1. **广告位管理** — 定义"在哪里放广告"（如：首页 Banner 轮播位）
2. **广告信息管理** — 在广告位中放入具体广告内容（如：第1张 Banner 图）

### 3.3 广告位管理

**操作路径**：广告管理 → 广告位管理

| 字段 | 说明 |
|------|------|
| 广告位名称 | 标识这个广告位的用途，如"首页 Banner 轮播" |
| PC 图片尺寸 | 建议上传图片的宽高，如 1920×500 |
| 手机图片尺寸 | 手机端图片尺寸，如 750×400 |
| 是否显示 | 控制这个广告位整体是否启用 |

### 3.4 广告信息管理（首页 Banner 轮播）

**操作路径**：广告管理 → 广告位管理 → 点击「信息管理」

首页 Banner 是广告系统的主要用途，以下是后台字段与前台展示效果的对应关系：

| 后台字段 | 前台效果 | 说明 |
|---------|----------|------|
| **主标题** | 大标题文字 | 支持 `\n` 换行 |
| **副标题** | 小标题文字 | 选填 |
| **描述** | 描述文字 | 选填 |
| **背景图** | 轮播背景图 | 留空使用默认渐变背景 |
| **前景图/视频** | 前景装饰图或视频 | 自动识别图片和视频格式 |
| **主按钮文字** | 大按钮上的文字 | 如"免费试用" |
| **次按钮文字** | 小按钮上的文字 | 留空不显示第二个按钮 |
| **跳转链接** | 点击 Banner 跳转的地址 | 可填站内或站外链接 |
| **打开方式** | 新窗口/当前窗口打开 | 默认新窗口打开 |
| **排序** | 轮播顺序 | 数字小的排前面 |

**前台效果示意：**

```
┌─────────────────────────────────────────────────────────┐
│  ┌──────────────┐                                      │
│  │ 主标题文字     │    ┌──────────────────┐             │
│  │ 副标题文字     │    │  前景图片/视频    │             │
│  │ 描述文字       │    │                  │             │
│  │                │    │                  │             │
│  │ [免费试用] [咨询]│   └──────────────────┘             │
│  └──────────────┘                                      │
│  ●  ●  ●  (轮播圆点)                                    │
└─────────────────────────────────────────────────────────┘
```

### 3.5 广告发布规范

| 项目 | 要求 |
|------|------|
| 背景图尺寸 | 1920×500 像素，不超过 500KB |
| 前景图 | 建议 500×500 像素内，PNG 格式 |
| 视频 | 建议 10MB 以内，MP4 格式 |
| 主标题 | 不超过 15 个字 |
| 副标题 | 不超过 25 个字 |
| 按钮文字 | 不超过 6 个字 |
| 轮播数量 | 建议 3-5 张，不超过 8 张 |

## 4. 栏目管理（分类体系维护）

### 4.1 功能入口

后台左侧菜单 → **栏目管理**

### 4.2 栏目说明

栏目用于对文章进行分类管理，分为两种类型：

| 栏目类型 | 前台效果 | 示例 |
|---------|----------|------|
| **列表类型** | 前台展示为该栏目下的文章列表，点击进入详情 | 新闻动态、知识问答 |
| **单页类型** | 前台展示为固定页面，编辑栏目的"详细内容"即可更新页面内容 | 公司介绍、产品中心 |

### 4.3 栏目基本操作

| 操作 | 说明 |
|------|------|
| 新增根栏目 | 创建一级栏目 |
| 新增子栏目 | 在指定栏目下创建子栏目 |
| 修改 | 编辑栏目名称、类型等属性 |
| 删除 | 删除栏目（有子栏目或文章时不能删除） |

### 4.4 栏目编辑说明

#### 基本信息
- **栏目名称**：前台显示的栏目名称
- **别名**：URL 中的地址标识（如 `gongsidongtai` → 前台地址 `/gongsidongtai`）
- **上级栏目**：不选则为根栏目
- **详细内容**：单页类型栏目的正文内容（如公司介绍页的正文）

#### 高级信息
- **分页数量**：列表类型栏目每页显示的文章数
- **栏目状态**：启用/禁用，禁用后前台不显示
- **PC Banner**：栏目页顶部大图，建议 1920×400 像素

### 4.5 注意事项

- **修改别名后**：前台 URL 会变化，旧链接会失效，需谨慎操作
- **删除栏目前**：先确认该栏目下没有文章，或已将文章迁移到其他栏目
- **禁用栏目**：仅前台隐藏，后台数据不受影响，可随时恢复

## 5. 常见问题与规范

### 5.1 常见问题

**Q：我想发布一篇案例/用户心声，但在内容管理里找不到单独的入口？**
- 新闻、案例、用户心声、知识问答都在同一个「内容管理」模块中发布。区别在于选择不同的**所属分类**：
  - 选"公司动态/行业动态/媒体报道" → 出现在新闻动态页
  - 选"行业案例"下的子分类 → 出现在案例中心页
  - 选"用户心声"下的子分类 → 出现在用户心声页
  - 选"知识问答" → 出现在知识问答页

**Q：前台文章没有显示怎么办？**
1. 检查文章状态是否为「显示」
2. 检查所属栏目是否已启用
3. 若文章在新闻动态子栏目下，确认前台切换到对应标签

**Q：Banner 轮播不显示？**
1. 检查广告位是否设置为「显示」
2. 检查该广告位下是否有广告内容
3. 检查广告的排序值是否正确

**Q：新增栏目后前台不显示？**
1. 检查栏目「状态」是否为启用
2. 若为列表类型，需在该栏目下发布文章才会有内容展示

**Q：修改了栏目别名后前台打不开？**
- 别名即 URL 地址，修改后旧链接失效，需使用新地址访问

### 5.2 内容发布规范速查

| 项目 | 建议 |
|------|------|
| 文章标题 | 10-30 字，包含核心关键词 |
| 文章摘要 | 50-150 字，概括全文 |
| 缩略图 | 380×239 像素 |
| Banner 背景图 | 1920×500 像素 |
| SEO 标题 | 每篇文章独立设置，含关键词 |
| SEO 描述 | 50-200 字，含关键词，不堆砌 |
