## 问题类别

| 类别 | 说明 | 典型表现 |
|------|------|----------|
| `需求理解偏差` | Agent 对用户意图理解有误 | 方案方向错误、反复沟通澄清 |
| `流程跳过` | Agent 未按流程执行 | 跳过测试、跳过审查、跳过文档 |
| `输出质量` | 代码/方案质量不达标 | 冗余代码、架构不合理、边界遗漏 |
| `上下文遗忘` | 长对话中遗忘关键约束或信息 | 重复询问、遗漏约束 |
| `工具使用` | 使用低效工具或工具使用不当 | 用 grep 而非 codegraph、重复读取文件 |
| `规则冲突` | 两条规则产生矛盾 | Agent 进退两难，无法决策 |

## 复盘机制

- **触发条件**：累计 10 条问题，或距上次复盘超过 2 周
- **复盘动作**：
  1. 按类别聚合问题，识别高频问题类别
  2. 针对高频类别，提出 `.claude/memory/rules.md` 优化方案
  3. 用户确认后更新规则
  4. 已处理的问题移到下方 `[已处理]` 归档区
  5. 更新 `last_reviewed` 时间戳和 `total_entries` 计数
